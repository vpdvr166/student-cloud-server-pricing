## 先把三个硬指标看清楚

**续费价，而不是首购价。** 大厂给学生的低价基本是“新用户首年专属”，第二年按官网原价续。云厂商给的价格表里，续费价往往比首年贵三到五倍。买之前去价格页翻一下续费规则，比看活动页有用。

**要不要备案。** 中国大陆节点必须备案才能用域名访问 80/443 端口。如果你只是想搭个博客、做个课设演示，香港、日本、美国、韩国这些节点不用备案，买完解析一下就能用。代价是延迟比国内节点高一些。

**能不能先小成本验证。** 学生最大的风险不是贵，是“买了发现不合用”。支持按天试用、能无理由退款的商家，实际试错成本会低很多。

## 不同用途大概需要什么配置

这一块没有标准答案，但可以按用途倒推。下面的推荐是基于普遍经验，不是某家厂商的规格：

| 用途 | 建议配置 | 说明 |
| --- | --- | --- |
| 学 Linux 命令、Shell 脚本 | 1核1G | 几乎不占资源，最低配就够 |
| 静态博客（Hexo/Hugo）、课程展示页 | 1核1G~2核2G | 静态站压力很小，流量比 CPU 更重要 |
| WordPress / Typecho 动态站 | 2核2G 起 | 数据库和 PHP 一起吃内存，1G 会很难受 |
| Python/Java 项目、Docker 练习 | 2核4G | 编译和多容器并行时内存是瓶颈 |
| 数据库、小型后端服务、多人课设 | 4核4G 以上 | 多服务同时跑，留点余量 |
| Minecraft 开服 | 高主频 CPU 优先 | 吃单核性能，核数多不如频率高 |

一个常见误区是拿 CPU 核数当唯一标准。学生场景里，内存先触顶的概率远高于 CPU 跑满。

## 几个容易忽略的细节

流量用完后不是停机，是限速。不同产品限到 1M 或 5M，网站还能勉强打开，但体验会明显下降。雨云的规则是当月用不完的流量可以结转到下个月，超了也能单独买流量包恢复速率，比直接吃超量账单方式温和。

硬盘扩容价格差别很大。高速固态云盘大致 0.4 元/GB/月（部分节点 0.3 元），机械盘 0.1 元/GB/月。如果只是放日志和备份，机械盘完全够用，成本差四倍。

国内节点备案这件事没有捷径。走国内机房、要用域名对外提供服务，就得走备案流程，时间成本通常一两周起步。学期中途要交作业的话，这个时间一定要算进去。

同一个节点不同分区的性能有差别。香港二区走三网优化、四区走 IIJ、五区是国际大带宽线路，适用人群完全不同：面向国内访客优先选优化线路，面向海外用户则国际线路更合适。

算得清就年付。年付 7 折相对月付省 30%，前提是你确定这台机器会用满一年。如果只是应付一学期的课程，季付 9 折更灵活，损失一点折扣换随时可以停。

不是。部分机型默认带一个 IPv4，海外节点和韩国一区的某些配置 IP 单独计费。如果你的用途只是内网穿透、定时任务、学习环境，共享或 NAT 端口映射也能用，能省一笔。

**试用之后还能用新用户券买吗？**
可以。雨云的规则里，试用后再下单仍按新购计算，不算续费。所以“先花 1 元试一天，觉得合适再用券正式买一年”是可行的路径。
